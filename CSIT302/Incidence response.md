# Incidence response

- Incidence response is used as a plan for responding to an [[TLCM|incident]].
- It details what and how a threat is managed 
### Foundation of an incidence response
| objective                              | scope                        | define/terminology                  | roles and responsibility                        | priorities/severity level                         |
| -------------------------------------- | ---------------------------- | ----------------------------------- | ----------------------------------------------- | ------------------------------------------------- |
| what is this IR planning to accomplish | who is this IR addressed to. | elaborate on the security incident. | state what must be done to recover and by whom. | functional impact of the incident in the business |
| =key points=                           |                              |                                     |                                                 |                                                   |
| clearly define the purpose             | company wide? departmental?  | provide examples                    | state the level of authority needed.            | state the information breached                    |
|                                        |                              |                                     | ==inform entire company of this==               | state the recoverability                          |
