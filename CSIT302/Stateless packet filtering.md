# Stateless packet filtering

- Filtering individual packets entering network
- Does not categories to each connection (no context)

| pros                   | cons                                       |
| ---------------------- | ------------------------------------------ |
| Fast                   | Cannot identify attackers                  |
| More resource friendly | Inaccurate(More false negatives/positives) |
