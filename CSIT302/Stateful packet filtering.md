# Stateful packet filtering

- Tracking active connection opened between network and endpoint. 
- Compares multiple packets 

| Pros                                      | Cons                    |
| ----------------------------------------- | ----------------------- |
| More secure (filtering with context)      | Slower                  |
| Accurate (Less false positives/negatives) | More resource demand    |
|                                           | Susceptible to [[DDOS]] |
