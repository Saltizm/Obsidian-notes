# NAC

- Network Access Control 
- A system to control network connection request prior to connecting   ^b50cc7

##### Definition 
is an approach to computer security that attempts to unify endpoint security technology (such as antivirus, host intrusion prevention, and vulnerability assessment), user or system authentication and network security enforcement

- Unify endpoint security technology --> make sure all accessing devices are secure
- User or system authentication --> make sure it is who it is ([[Authentication]])
- Network security enforcement --> security measures ([[IDS and IPS]])

##### Evaluation criteria 
- latest patches 
- antivirus enabled 
- personal firewall enabled 
- compliance with mandate security policies

##### Placement
- Before the firewall
