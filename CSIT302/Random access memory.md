Random Access Memory (RAM) is a type of volatile computer memory that temporarily stores data and machine code currently being used by a computer's operating system, applications, and processes. Unlike storage devices (e.g., HDDs or SSDs), RAM loses all stored data when the power is turned off.

### Key Characteristics

|                   | explanation                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------- |
| Speed             | Much faster than permanent storage, enabling quick access for active tasks.              |
| Random Access     | Allows the CPU to read or write data from any location in near-constant time.            |
| Temporary Storage | Holds active programs and data for quick retrieval but does not store files permanently. |
| volitility        | RAM requires constant power to retain data.                                              |
### Types of RAM

- **DRAM (Dynamic RAM):** Requires periodic refreshing; used in most PCs (e.g., DDR4, DDR5).
- **SRAM (Static RAM):** Faster and more expensive; used in CPU caches.
