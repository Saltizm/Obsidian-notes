# Degaussing

### HDD
➢It is the process of reducing or eliminating an unwanted magnetic field (or data) stored on tape and disk media such as computer and laptop hard drives → Does not work for SSD. 
➢Deleting the data using software is generally not a secure way.
### SSD
➢There is no standard way for this. 
➢One of the suggested way is encryption: Encrypt the disk with a long random key and forget the key. Then, format the disk.
