# BIA(business impact analysis

- [[Incidence response|recovery strategies]] Triage.
### Steps
ID critical IT resources $\rightarrow$ ID disruption impact $\rightarrow$ Develop recovery priority
#### Critical 
- If it affects end users -> it is critical 
#### Disruption impact
- calculate *allowable outage times* 
- $affordance = \dfrac{outage-time-cost}{cost-of-recovery}$
#### Priority
- rank risk according to *allowable outage times*
- solve issue in sequence
