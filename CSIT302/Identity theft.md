# Identity theft

stealing someone's identity to get security clearance. 

### Method
#### Honey trap
- get close to target to access more personal information 
- use personal information to steal identity 
	- Dob
	- Parent maiden name(security question)
	- Address
	- School name

##### Prevention
- [[Password policy]]
- Limit sharing of personal information
	- Upon creation of account
	- Upon posting 
- Update privacy settings
- Regular pwn checks
- Verify links sent by peers
