# Attack surface

- All possible entry point and vulnerability within a system

### Types
#### On-premise
- Network perimeter devices, VMS and [[Hypervisor(networking)]].
- Risk posted from:
	- [[social engineering]]
	- [[Internal reconnaissance]]
	- [[Ransomware]]
##### Remote access
- Off shore workers connect through the internet 
- 3rd party software posting security risks:
	- [[Cloud computing]]

##### BYOD
- Bring your own device
- Vulnerability from personal devices (laptop, phone etc)
