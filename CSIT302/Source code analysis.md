# Source code analysis

- Check for potential vulnerabilities in the source code
- Protect against [[Reverse engineering]]
- Usually using automated [[SaaS]] such as Checkmarx(www.checkmarkx.com)

| Benefit             | Demerit                                                                    |
| ------------------- | -------------------------------------------------------------------------- |
| Simpler and quicker | Lower success rate (vulnerabilities that are unknown are hard to pinpoint) |
