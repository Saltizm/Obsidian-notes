# Asset inventory

- List of Devices owned by an organisation 
- Determine possible attack vectors that require [[Security control|security software]]
### Use of an asset inventory
- Highlight compatibility issue with security software 
- Maintain a good update schedule with all devices
- Provide *good estimate of cost on security* 
### Challenges 
- List has to be manually updated and is prone to human error
