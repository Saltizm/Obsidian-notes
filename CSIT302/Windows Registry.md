# Windows Registry

- hierarchical database storing 
	- critical system
	- application
	- user config
- Setting for Windows
- Pretty much fucked if it gets to this point 

### Exploits
#### Kernel level Executions
- Malware can be executed at the kernel level. 
- making it undetectable 
- and persistent 

#### Modifying system settings
- Can disable windows defender
- Can disable firewall 
- Increase user privilege ([[Access and privilege Escalation]])
