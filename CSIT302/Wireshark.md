### .
- sniffing tools with a user-friendly interface and powerful packet interpretation
### Color coding
- Purple -> [[TCP]]
- Blue -> [[UDP]]
- Black -> Error packet 
### Modes/Functions
#### Promiscuous mode
- Pass all traffic directed at the [[NIC]] (network interface card) to the [[computers|CPU]]
- Read ALL packets in traffic (even if not addressed to host)
#### Following stream
- Displays the full [[TCP]] 3 way handshake
