- Remote boot from a external drive
- Using ubuntu select **Try ubuntu*** instead of **install ubuntu**
- Once booted, files are accessible 

#### Mitigation
- Enable Full-Disk Encryption (FDE) 
	- Use **BitLocker** (Windows Pro/Enterprise) or **VeraCrypt** 
- Set a BIOS/UEFI password to prevent unauthorized booting from external devices.
- Disable External Boot in BIOS
- Keep computers in a secure location to prevent unauthorized physical access.
