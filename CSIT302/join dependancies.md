# join dependancies

- Join dependency is when a table can be broken down into smaller tables without:
	- Loss of information
	- Creation of extra information
- In other words, Join dependency is when a table can be reconstructed from its components when decomposed 
>[!note]-
>If 2 tables are deemed to have a loss of information. join dependency dictates that it must be combined
