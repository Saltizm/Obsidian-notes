# Diversion theft

To manipulate delivery/transport company to redirect their deliveries to a designated location set by malicious actors(usually for collection) instead of the actual delivery destination.

Key principle used:
- [[Consistency]]
- [[Validation]]

### How does it work
it exploits the chain of command for most companies. Without proper security training; Workers and managers will listen to the request of an authority without question.
