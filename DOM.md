A document encompassing all parts required to load a webpage.
contains:
- html document
- forms
- inputs 
- images 
DOM allows for dynamic updates without refreshing the entire page.
traditional
- old html page -> new html page
with dom
- html page
	- images
	- forms
	- clock graphic
		- hour value -> new hour value
DOM contain a tree that is rendered from parent to child. Subsequent updates to children can be refreshed at a child level.
