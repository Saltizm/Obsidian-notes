# Minimal key

- Minimal key is a [[Super key]] that has the *Least* number of attributes possible.
- Removing any would deem the Minimal key non-unique
- A minimal key can be a [[Candidate key]] 

> [!example]- Example
> Assume
> *Name, email, Phone number*
> to be the *Super key*
>
>
> A minimal key will be:
> *Name, email*
>
