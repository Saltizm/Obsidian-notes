### Functions
A function is a relation that satisfy the condition:
assuming relation **aRb**
- domain of function == a
- all values of a **MUST** be mapped to **ONLY ONE** value of b

#### terminology 
Domain (a) - a set of possible inputs
Codomain (b) - a set of possible outputs
Range - the actual outputs
