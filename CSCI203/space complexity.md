# space complexity

Space complexity (memory requirement) is the number of **memory positions** required to execute an algorithm relative to the size of data *n*.

### variables of space complexity
- number of variables
- number of loops 
- use of pointers (auxiliary space)
- method of processing
	- parallel processing
	- linear processing
