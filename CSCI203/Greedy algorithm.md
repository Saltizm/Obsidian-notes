# Greedy algorithm

Greedy algorithm take the ***Locally optimal choices*** in hopes of a ***globally optimal solution***.

##### Characteristics
- No [[Backtracking]]
- simple design

Iterate through a Candidate set.
if candidate is not valid for the solution. Add to rejected set
if candidate is valid for the solution. Add to selected set.
