# Change request board

Provide guidelines for:
- Preparing change request 
- Evaluate change request
- implementation of approved change request

THEY DO NOT submit/manage CHANGE REQUEST.
The person in charge as shown in [[Project organisation chart]] does the above. CCB(change request board) only creates the **template**.
