# Scope statement

A project scope statement is **a clear definition of the boundaries of a [[Project management|project]]**.

![[Pasted image 20240603000740.png]]

#### Procurement
A Scope statement for [[Outsourcing (Procurement)]] is called a Statement Of Work ( SOW ).
A SOW is used for:
- Project Bidding
- Tracking project

Content:
- The work required for the particular contract
- Purpose 
- [[deliverables]] from contractors

Very similar to Scope statements as Procurement is essentially starting a separate project whereby work is allocated to contractors.
