# Outsourcing (Procurement)

Acquisition of good and services from an outside source. 

#### reasoning for outsourcing

| Point                                          | Explaination                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Access skills and technologies                 | Some cutting edge technology is held by only a handful of firms                                                                                                                                                                                   |
| Reduce [[Cost benefit analysis\|Cost]]         | Other entities which specialise in providing the good and services can do so with lower cost.                                                                                          ( a chinese factory can manufacture parts cheaper than us) |
| Allow more focus on [[Scope statement\|Scope]] | No need to expend resource on goods and services that are out of the project specialty ( security expert, accountant etc.)                                                                                                                        |
| Flexibility                                    | Can change supplier if unsatisfied, wide variety of choice                                                                                                                                                                                        |
| Increase accountability                        | All outsourcing is contractual and accountability on the providing party is legally enforced                                                                                                                                                      |


#### Conducting procurement
1. Decide who to ask for the work ([[Cost benefit analysis]])
2. Send appropriate documentation to potential sellers ([[Scope statement|Statement Of Work(SOW)]])
3. Obtain bids
4. Select seller
5. Award a [[Contract]]

#### Controlling procurement

Once a procurement [[Contract]] is signed. Any further verbal/ written acts issues by figures of authority will be considered **Legally binding**

So it is important to:
- Manage [[Meeting minutes]] and follow-ups
- Document amendments ( record verbal contract/ save emails)

However some changes are not ideal and will result in [[Risk]].

##### Closing procurement
- ensure [[Scope statement|all work are satisfactory]]
- completing and settling contract
