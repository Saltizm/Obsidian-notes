# cost baseline

Cost baseline is a project management estimate of the budget required to complete a project successfully.

##### Formula
Cost baseline = Project cost + Contingency 

##### Estimating project cost
A project cost can be estimated by summing the 
- Planned cost  ( material, resources etc )
- Fixed cost      ( employee wages, rent, bills etc )
