# Ransomware

Ransomware is a piece of malicious software that takes a system's files hostage and demand for a *ransom*. ^7c991b

Features:
- is for **profit**
- can corrupt or destroy files 
- locks the computer before ransom is collected

Signs of being infected:
- Cant access computer 

Common ways to be infected:
- downloads/ attachments
  - *usually in...* :
		- emails
		- private messages from infected devices
		- forums

### Case study
WannaCry incident:
[[Dropper]] - Eternal blue, an exploit developed by the NSA to exploit the SMB protocol 
[[Payload]] - Ransomware that requested for 300usd in 3 days, or 600 in 7 days. ([[Scarcity]])
Time frame - May 2017

Lockbit 3.0:
Dropper - [[RaaS]], utilises [[Bruteforce attack]] to gain access to [[Remote Desktop Protocol (RDP)]] and [[VPN tunneling|VPNs]]. Also has tools to perform [[Phishing]] attacks.
[[Payload]] - Ransom is up to the amateur attacker
Time frame - 2022 - Current
