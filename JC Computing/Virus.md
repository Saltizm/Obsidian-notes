# Virus

A malicious software that executes through other software or services.
Macros in document
Executable in windows ^c234e0

Feature:
- A virus can lay **dormant** and **undetected** (until the user executes an infected file)
- Keylogging
- Corrupting files
- **Can spread to other devices**

Common ways to be infected:
- text or email attachments
- downloading of suspicious applications 
- clicking dubious links
- interacting with files sent from an infected computer
