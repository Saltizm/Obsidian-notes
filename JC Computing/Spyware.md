# Spyware

Spyware is a malicious software that gather infomation about the user. 

Features:
- Is for **profit**
- Keylogging
- Screencapture 
- is carried out **without the users knowledge**
- **regularly send data** to the attacker to be sold

Signs of being infected:
- physical signs: ^3ab2eb
	- computer runs slower
	- frequent crashes 
- unusual activities: ^939914
	- having your password changed without your knowledge
	- browser main page set to another page. May or may not be revertable
	- unknown application opening at startup
	- pop ups

Example of spyware:
	[[Trojan]]
	[[Adware]]

Common ways to be infected:
- downloading bundleware ( addtional software bundled with the desired application )
- downloading files from suspecious links
	- *usually in...* :
		- emails
		- private messages from infected devices
		- forums
