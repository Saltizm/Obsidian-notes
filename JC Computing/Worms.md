Worms are malicious software spread throughout a network usually via a *network vulnerability*.
Self replicating (standalone) ^365fd0


Features:
- can be autonomously spreaded
- rapidly duplicates itself onto different files
- can delete files
- usually works **undetected**
- can **spread to other devices**

Common ways to be infected:
- clicking on an attachment through an email or message

Signs of being infected:
- Disk space running out
- Computer runs slower
- Missing files
