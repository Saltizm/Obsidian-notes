# Proxy servers

A intermediatry server used to let users in a private network access the internet.

Purpose:
- [[server|anything that can be done by a server]].
- provide a bypass to firewalls to the internet. (censorship etc)
- [[NAT]] 
- [[Firewall#^e7d30a|can have a firewall installed]]
- log ongoing traffic
