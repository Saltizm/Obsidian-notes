# CIA triad

Confidentiality - is the data accessible only to those authorised 
- network eavesdropping
- credential stuffing
Integrity - is the data/system only modified intendedly
- ACE - arbitrary code execution
Availability - are the data/system accessible when/how it is intended to be
- Denial of service
