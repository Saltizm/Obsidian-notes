# Integrated CASE tools

Examples of tools used:
- [[Project management systems|Project libre]] (planning)
- [[UML diagrams]] (analysis)
- VSCode (implementation)

Case tools (Computer Aided Software Engineering tools) are software that is used to aid in the development of projects.
TLDR; it is just software that aids in development

#### Upper CASE tools
Used for:
- [[Project management|planning]]
- [[System analysis (Main)|Analysis]]
- [[Human computer interactions|Design]]

#### Lower CASE tools
Used for:
- Implementation
- Testing
- Maintainance
