# FURPs

FURPs is a model that classifies software quality attributes.
FURPs is used to classify both functional and non-functional requirements for a [[system]]

**FURPs stands for**
[[Functionality]]
[[Usability]]
[[Reliability]]
[[Performance]]
[[Security]]

outside of there requirements others can be implemented but these are the fundamental requirements needed for a good [[system]].
