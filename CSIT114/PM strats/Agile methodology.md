# Agile Methodology

Agile is an adaptive [[SDLC]] approach that embraces change. Like [[Spiral]], it is iterative rather than linear and risk-avoidance driven.

## Advantages and limitations

| Advantages | Limitations |
| --- | --- |
| High customer satisfaction and user involvement | Less approval and documentation control |
| Close stakeholder collaboration | [[Scope Creep]] |
| Fast, incremental prototypes | Requires a highly skilled, self-managing team |
| Flexible, problem-solving approach | Decisions are made by the team |

## Scrum

[[SCRUM|Scrum]] is an Agile framework for delivering incremental changes. See that note for its roles, artifacts, events, and practices.
