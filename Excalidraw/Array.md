### Behaviour 
Array is initialised with the lower bound and upper bound.

each element is access through an index.

Indexes:
Lower bound = 0
Upper bound = n

### Use case
Higher dimensional arrays (Nested arrays)
- Can be used to store data for positional information for calculations

the [[runtime complexity]] is O(n^d) where d is the depth of the nested array
