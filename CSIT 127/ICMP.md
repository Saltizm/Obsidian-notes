# ICMP

### .
- Part of the [[IP|internet protocol]]. Use by routers and nodes (microcomputers) for [[packet forwarding]].
**Purpose**
- Error reporting
	- report errors and terminate packets that are invalid
		- have invalid IP addresses
			- clash
			- corrupted
		- exceeded [[TTL and Hop limits]]
