# Protocol

A protocol is a set of rules for communication between devices​

Protocols control 3 factors:
- Syntax. The structure or the format of the data, meaning the order in which they are presented.​
- Semantics. The meaning of each section of bits.​
- Timing. When data should be sent and how fast they can be sent.​

Protocols:
- POP3 - Post Office Protocol 3​
- IMAP - Internet Message Access Protocol​
- SMTP - Simple mail Transfer Protocol​
- [[HTML]] - hypertext transfer protocol​
- FTP - file transfer protocol​
- [[TCP]]/[[IP]] - Transmission Control Protocol/Internet Protocol​
- PPP - Point-to-Point Protocol, TCP/IP over the phone lines
- [[ARP]]
- [[UDP]]
- [[DHCP]]
- [[ICMP]]
