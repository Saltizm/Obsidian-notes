# VoIP

Transfer of Voice signals using [[Packet switching]]. 
A temporary [[IP]] address is assigned to each transmission.

Used to be limited in use due to [[IPv4|IP scarcity]] but with the introduction of [[IPv6]] this is no longer an issue.
