# packet forwarding

the relaying of packets between network segments via nodes (intermediate routers) in a network.

Type of packet forwarding:
- Unicast ( to one )
![[Unicast_forwarding.png]]
- Multicast ( to many )
![[Multicast_forwarding.png]]
- Broadcast ( to all )
