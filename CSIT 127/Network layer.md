In the seven-layer [OSI model](https://en.wikipedia.org/wiki/OSI_model "OSI model") of [computer networking](https://en.wikipedia.org/wiki/Computer_networking "Computer networking"), the **network layer** is **layer 3**. The network layer is responsible for [packet forwarding](https://en.wikipedia.org/wiki/Packet_forwarding "Packet forwarding") including [routing](https://en.wikipedia.org/wiki/Routing "Routing") through intermediate [routers](https://en.wikipedia.org/wiki/Router_(computing) "Router (computing)").[[2]](https://en.wikipedia.org/wiki/Network_layer#cite_note-2)

<h2>Function</h2>
- Forming [[Packet switching|packets]] 
- Host addressing 
	- Setting the destination (IP address) of each packet 
- [[packet forwarding]]

<h2>Anatomy</h2>
Protocols:
- [[IP]] ( forming packets n shi )
- [[ICMP]] ( multicast connectionless )
- [[DHCP]] ( auto assign IP address)
- [[NAT]] (subnetting)
