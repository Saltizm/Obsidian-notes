# infrared

infrared is a short ranged wireless transmission medium.

transmit data using intense and weak pulse. ( [[Digital]] )

A infrared transmitter  consist of two parts.
- Infrared emitter 
- infrared detector

| advantages                                          | disadvantages                         |
| --------------------------------------------------- | ------------------------------------- |
| secure connection                                   | dust and smoke                        |
| low power consumption                               | health concerns ( at higher voltages) |
| fast response time                                  | difficult to have many connections    |
| good stability( when used intendedly)               | short range                           |
| good durability                                     | speed of transmission                 |
| does not interfere with other communication signals | lack of mobility                      |
| cannot penetrate walls                              |                                       |

There are two types of infrared transmitter.

| type                           | uses                  |
| ------------------------------ | --------------------- |
| directed infrared transmission | one to one connection |
| diffused infrared transmissoin | one to many connection                     |
