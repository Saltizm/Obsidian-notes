# Circuit switching

a sub-network in which a dedicated circuit is established between sender and receiver and all data passes over this circuit.

It is a connection network structure
![[circuit switching.jpg]]\

## Mechanism
The path of least cost is found and a direct network connection is formed. Then, the data is transmitted to the recipient in its entirety 

Used in:
- telecom (defunct)
- broadcast network
