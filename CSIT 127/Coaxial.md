[[wired|Coaxial cable]] consist of a single copper conductor to transmit signals.
This means it has no internal [[Crosstalk]] and it is able to transmit higher bandwidths.

| pro                                | cons                                |
| ---------------------------------- | ----------------------------------- |
| Decent [[bandwidth]] and [[channel capacity]]                    | stiff and bulky                     |
| lower error rate than twisted pair | expensive                           |
| Greater spacing between repeaters  | need to be grounded                 |
|                                    | susceptible to lightning strikes    |
|                                    | brittle (high cost for local moves) |

![[CoaxialCable.PNG]]

Commonly used in [[Bus|bus architecture]] because of its large bandwidth.

coaxial is used in:
- television
- [[Internet|internet service]]

Use of coaxial cables however has been mostly defuncted in Singapore as the government mandates fiber.
