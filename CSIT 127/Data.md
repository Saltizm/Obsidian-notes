# Data

Data are entities that convey meaning.
The type of information it can represent is separated into types.
- [[Text]]
- [[Image]]
- [[Video]]
- [[Audio]]

Data is transmitted through [[electricity]] or [[electromagnetic]] encoding in the form of [[Signal|signals]].

Data can be stored both [[Digital|Digitally]] or [[Analog|Analogously]].
