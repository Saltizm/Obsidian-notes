<h2>TTL</h2>
Time to live is a value used to determine how long a packet can stay in a network. 

Denoted in ticks which is equivalent to a second in real life.
eg. 4.25 min --> 225

<h2>Hop limits</h2>
The number of times a packet can "hop"( move to a different node ) in a network.
