Uniform Resource Locator is an addressed used to find every document on the internet.

<h2>Anatomy</h2>
![[URL anatomy.png]]

Protocol:
The web protocol that can be used:
- [[HTTP|HTTPS]]

Subdomain:
- used to separate a website into different sections
- eg. A school website can have a *student.* subdomain for student and *school.* subdomain for the school website

Domain name:
- unique name used to access websites

Root domain:
- domain of the main page
- in diagram: *websitename.com*

Path:
- filepath of the displayed page

top-level domain:
- For identifying domain name category 
- TLD types:
	- Generic TLDs: *.xyz .com .org*
	- Country-code TLDs: *.us .sg .au*
	- Sponsored TLDs: *.app .gov .edu*
	- infrastructural TLD: *.arpa* (the first tld)
	- Reserved TLDs: *.localhost .example*
