# T5

#### Depth first. 
FILO
 $$Time\ complexity:\ b^m$$
 $$Space\ complexity:\ bm$$
 where m is the depth.
#### Breadth first search.
FIFO
$$Time/Space\ complexity:\ b^s$$
 where s is the solution depth
#### IDF (iterative depth first)
incremental depth for Depth first search
#### UCS 
uninformed weighted search that picks the path of least cost.
$$Time/Space\ complexity:\ b^{C*/\epsilon}$$
where C* is cheapest solution path cost 
where E is lowest action count 

C*/E appx. Depth
##### Heuristics 
H(n) = 0 
#### A* 
informed weighted search with cost approximation 
#### Admissible heuristics
$$0\le h(n)\le h^*(n)$$
IF the estimate is more than 0 and less than the actual cost
##### Consistent heuristic
if the heuristic estimate satisfies the **triangle inequality**
##### Heuristic dominance
when combining heuristics, one value is consistently lower than the other.
Solution:
- Max (h1, h2)
This is done when applying **composite heuristics**
