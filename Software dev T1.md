# Software dev T1

RUDS

User story - needs defined by actors (users)
### User Admin (User)
- Create - want to be able to Create user profiles
- Retrieve - want to be able to Retrieve user accounts
- Update - want to be able to Update user accounts
- Delete - want to be able to Delete user accounts
- Search - want to be able to search for user accounts



1. Support and manage different types of user accounts and user profiles (i.e. user admin, Fund Raiser
(FR), Donee, platform management).
2. Support FR to manage their fund raising activity (FSA)
3. Support Donee to search, view, save (into a favourite list) of potential fund raising activities
4. Support FR to track the potential interests on their FSA (i.e. the number of views, the number of times
being shortlisted)
5. Support FR to search and view history of the previous completed FSA, filtered by services, date period
6. Support Donee to search and view history of the donations made and the progress of the FSA, filtered
by FSA categories, date period
7. Support platform management to manage FSA categories and get reports (daily, weekly, monthly)
