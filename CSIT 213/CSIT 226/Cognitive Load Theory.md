# Cognitive Load Theory

A universal set of learning principles that are proven to result in efficient instructional environments as a consequence of leveraging human cognitive learning process.

TLDR;
human [[InformationIO|sensory]] and [[short term memory]] is limited and has to be worked around. 

## Anatomy
![[CLTmodel.PNG|500]]
A person's memory capacity is like a rubber band.
It is able to be stretched but doing so is tiring.
Additionally if it is stretched too much it might snap(run out).

so information(cognitive load) is separated into 3 categories.
- Germane Load
	- The cognitive load enforced from the process of **learning**. 
	- Involves transfer of information into the long-term memory through [[schema construction]]
- Extraneous Load
	- The cognitive load enforced from extra/unnecessary [[Information IO|stimulus]] 
	- Does not help with learning
- Intrinsic Load
	- The cognitive load enforced by the complexity of the information
	- Cannot be reduced through design
	- [[mental model|prior knowledge]] can help lessen it

Cognitive Load examples:
- Split-Attention
	- unnecessary splitting of attention. 
	- eg. having instruction on how to make the cake and the frosting at the same time.
- Redundancy effect:
	- having additional text to a diagram that does not require it
	- over-explaining
	- eg. explaining all of the elements in a flowchart 
- Element interactivity:
	- information requires knowledge from different parts (ie related) to understand
	- eg. a cake recipe with different components that has to be made from scratch
