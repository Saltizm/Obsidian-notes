# Attention

Human have selective perception to help concentrate on one thing without being overwhelmed by stimulus.

Loud and vibrant design can catch the attention of the user. 
However, if it is in excess it can be distracting and cause [[Cognitive Load Theory|cognitive load]].

distractions can be anything that causes the user to pay attention to. It is not limited to physical elements.

a thought can be distracting 
so can emotions
