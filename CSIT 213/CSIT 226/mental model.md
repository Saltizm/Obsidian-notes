# mental model

A mental model is a set of beliefs and ideas that people form based on their [[Information storage (memory)|long term memory]](experiences).

example:
digital : When I want to walk in a game, I use WASD to move
real-life: When there is a handle on a door, I can pull on it

## Types
- Unscientific
- Partial
- Unstable
- Inconsistent
- Personal
