<h2>Anatomy</h2>

Design ultimately is a game of balancing between different solutions:
Every solution has an ***Opportunity Cost*** which is
any other solutions forgone.

The job of designers is to find the solution with the least ***Opportunity cost*** based on several factors:
- [[Human computer interactions]]
- Time
- Resources
- [[Technical]] [[requirement]]

To begin. We must first determine the nature of the problem.
Is it well understood? Is it not?

Predictive Design:
- Assume the [[system]] is well understood
- Development project can be planned and organised in advanced. development follows the plan

Adoptive Design:
- Assume the system requirements are "not well understood"
- Requirements only emerge while completing the preliminary work
