
<h2>Constraint</h2>

Restricting the possible actions that can be performed
-  Helps prevent user from selecting incorrect options
-  Physical objects can be designed to constrain things

(e.g. only one way you can insert a key into a loc)

<h2>Affordance</h2>

Allowing the desired actions to be performed
- create a proper narrative(mapping) for a product
- size and colour can be used to signal affordance
