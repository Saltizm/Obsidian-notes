# Information storage (memory)

- [[Information IO|Sensory]]
- Short-term(working)
- Long-term([[mental model]])

## Human Cognitive Architecture
==Long term memories== are formed from the repeat reinforcement of a ==**short term memory**== through ==stimulus(sensory)==.

![[humanmemorymodel.PNG]]

However short term memory has a limit. If there is not, everyone would be able to learn everything at one go.

The [[Cognitive Load Theory]] takes into account this limit to optimise learning.

Methods for increasing learning:
- [[scaffolding]]
	- fundamental functions made initially available 
	- advanced functions slowly introduced with increase expertise
![[training wheel example.png|500]]
- [[Case sensitive method]]
	- hide functions not available 
	- **common in modern designs**
