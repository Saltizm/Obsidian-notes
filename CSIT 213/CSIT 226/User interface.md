Part of the application that the
user use to interact with the computer
and for the computer to communicate results back with.


![[ACM SIGCHI traditional model.PNG]]
<h2>Anatomy</h2>
- [[Attention]] 
- [[Perception]]
- [[Information storage (memory)|Memory]]
- [[mental model|Learning]]
- Reading, speaking and listening (interaction)
- Problem-solving, planning reasoning and decision making. (application)

besides the [[Interactive Design]] principle UI require additional principles:
- Familiarity
- Predictability
- Recoverability
- Guidance
- Diversity

To begin, UI has to address 2 problems:
How the information is presented to the user from the system?
How should the user enter information( communicate ) with the system?

This can be answered by inferring from the 
[[Evaluation Action cycle]](EEC)

With the initial requirements addressed we can move on to forming the [[Layered Framework]] 

<h2>Types</h2>
- Command Line interfaces(CLI)
- Graphical User interfaces(GUI)
- Natural User interfaces(NUI)

<h2>Philosophy</h2>
why care about UI?:
interactions with technology is cognitive ([[Information IO]])
Therefore, [[Cognitive Load Theory|limitations]] has to be accounted for

UI also better connect the application's [[Mapping]] with the user's [[mental model]].
UI also provide [[Constraint and Affordance|guidance]] to the users for a better interactive product.
