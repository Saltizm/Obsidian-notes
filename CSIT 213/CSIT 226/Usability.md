# Usability

goals of usability:
- effective to use
- efficient to use
- safe to use
- have good utility
- easy to learn
- easy to remember how to use

good usability designs are *invisible* 
Should be difficult to notice

design principles for usability:
- Visibility
	- reduce short term memory load
- Feedback
	- offer informative feedback
	- design dialog to yield closure
	- simple error handling
	- easy reversal of action
