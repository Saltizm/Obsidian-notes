# Human computer interactions

is a discipline concerned with the [[Design Thinking|design]], [[System analysis (Main)|evaluation]] and implementation of [[Interactive Design|interactive]] computing systems for human use and with the study of major phenomena surrounding them.

To summarise:
HCI is the study of how people use computers and how we can improve that.

## Anatomy
[[Human]]
- end user of computer system
- sponsor (client) of the computer
- others (anyone not the client)
**Computer**
- Hardware (peripherals)
**Interaction**
- Communication between human( client ) and computer
	- user tell computer what they want 
	- computer communicates results

How well a user interacts with a computer is determined by:
- [[Usability]]
- [[User experience]] (UX)
- [[User interface]] (UI)

## philosophy
Rationale for HCI:
- increase productivity
- accessibility for new users
- ease of usage for existing users
- reducing stress and discomfort
- brand image 

what to do for HCL:
- design based on clear understanding of user, task and enviroment
- rely on user-centred evaluation
- use versions and iterations
- must address user experience entirely (physical, emotional etc)
- consider many stakeholders

No Nos of HCI:
- generalising your users
- primary user might not always be the client

## Process
seek context of use > specify user requirements > create design solutions > evaluate design solutions > repeat
