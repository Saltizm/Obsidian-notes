# Evaluation Action cycle

It is a breakdown of the interactions between a Human and a computer through a UI. 
![[EEC.PNG|500]]

The "GOAL" sections would make more sense if it is user/human.
Execution:
Human - Articulation
- how an element is shown
- improvements 
	- clustering/grouping
	- patterns 
Computer - Performance
- actions performed
	- improvements
		- t[[scaffolding]]
		- [[Case sensitive method]]
Evaluation:
Human - Observation
- how user reacts to element
- improvements
	- [[Usability]]
	- [[Heuristics]]
System - Presentation
- how the system show the action performed
- improvement
	- tactile feedback
