# Interactive Design

Designing interactive products to support the way people communicate and interact in their everyday and working lives
![[interactive design.PNG]]

| role                  | description                                                   |
| --------------------- | ------------------------------------------------------------- |
| interaction designer  | involved in design of interactive aspects                     |
| usability engineers   | evaluates products using [[Usability]] methods and principles |
| web designer          | design ui                                                     |
| information architect | plan and structure interactive products                       |
| Ux designer           | all of the above and field studies to inform the design of products                                                              |
