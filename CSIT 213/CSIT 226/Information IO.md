# Information IO

- Visual
	- 2 stage process
		- reception
		- interpretation
	- context helps with **interpretation**
- Haptic
	- immediate feedback
	- vague
- Auditory
	- spatial 
	- auditory filtering helps focus down on a sound and zone out from others
- Movement
	- delayed ( reaction time + movement time )
	- varied ( depend on reaction to stimuli )
