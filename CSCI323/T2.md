Margin - girth of the Decision boundary 
Weight - how much the the feature represented
Target(y) - data point that is from the target sample 
Input Feature vector(x) - variables to show how much a feature is represented in a data point
Feature mapping(phi(x)) - transform the non linear points onto a linear line(or other norminal forms).

Bias - the amount the margin shifts along the y axis. This is automatically updated through gradient descent

SGD - updates bias using gradient descent upon each proceeding layer
