# Pen testing techniques

### Process
- Information gathering
- Scanning ( using port scanners like [[Nmap]])
- Exploitation 
- Covering tracks 
- Maintaining access ([[Rootkits]] etc)
#### Information gathering
- Intelligence gathering( [[Threat intelligence]] )
- information reconnaissance ( [[External reconnaissance]] )
- Can be regarded as an attack (cause considerable damage)
##### Information type
- Technical 
- Administrative
- Physical 
##### Methods for information gathering
- Passive 
	- Do not engage target ( receive information from [[OSINT]] )
	- Low impact
- Active
	- Engage the target ( [[social engineering]] attacks )
	- Higher impact
