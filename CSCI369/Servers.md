# Servers

- Service computers 
- Used to provide a service to Clients in the Client-Server model.

### Types
#### Application server
- Used to host Web Apps
- Local/Internet
- [[SaaS]]
#### Web server
- Used to host Web pages 
- Internet
#### Computing server
- Raw stat sticks 
- Local/Internet
- [[IaaS]] 
#### Database server
- Stores data
- common architecture such as [[SQL]], [[noSQL]]
- Local
#### Files server
- Stores human readable files
- Uses an OS file directory
- Local
#### MISC servers
- mail server
- proxy server
- communication server ([[CSIT302/DNS]] server)
