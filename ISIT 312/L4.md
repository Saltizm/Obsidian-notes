Groupby - aggregate duplicate rows
Distrubuteby - break row into duplicates 
Clusterby - Distrubuteby + sortby

Grouping_id - binary value assigned to columns to represent if it is aggregated or not

1 - full representation
0 - aggregated

Multiple rows

grouping_id can be use to express multiple columns 

1 1 - full detail from both rows
1 0 - cumilative one second row
0 0 - cumilative on both rows
