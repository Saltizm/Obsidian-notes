OLTP - transactional database 
- made to process many queries 
- used for online transactions (Online transaction processing)
- faster query response time but smaller capacity (small portion can be accessed at once)
OLAP - analytical database 
- made to do data analytic
- slower but higher capacity (more can be accessed at once )

OLAP / OLTP access database warehouses 
- multidimensional model(tables)
	- used because more closely represent real life data ( operational data are usually tracked continuously hence the extra axis)

tables instances -> members
axis -> attributes(headers)
cell/facts -> rows

multidimensional tables
- usually sparse (can be dense)
- members
	- hierarchical arrangement
	- allow for course grained and fine grained data retrieval ( will the query span through all members or just a group of members)

additive measures : data is summed across 2 axis

semi additive measure : data is summed across 1 axis

non additive measure : data is individually represented

distributive measure : data is summed in groups with relations

algebraic measure : data is processed by a algebra expression

Roll up : pivot(move to a different face of the cube.) (change to another 2 axis)

Drill down: change from course grained to fine grained

Sort : order the values by one axis

slice : taking a 2d snapshot of a member

dice : taking a submember of a member
